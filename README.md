# Fletes y Mudanzas Sabino

Sitio estático de una sola página desarrollado con Astro para Fletes y Mudanzas Sabino.

## Requisitos

- Node.js 20 o superior
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación para producción

```bash
npm run build
```

El resultado optimizado se genera en `dist/`.

## Cotizador

El formulario valida origen, destino y tipo de servicio en el navegador. Después prepara un mensaje con los datos capturados y abre WhatsApp hacia el número oficial. No almacena ni envía datos a un servidor.
